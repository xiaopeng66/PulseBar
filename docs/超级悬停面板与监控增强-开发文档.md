## 1. 全局约束与已知坑（每个 Stage 开工前过一遍）

1. **本机 PDH 全坏**（0xC0000BC0）。一切新数据源禁止走 PDH：GPU 用 NVML，磁盘用 `IOCTL_DISK_PERFORMANCE`。
2. **取不到的数据不伪造**：值无效时显示 `--`（与现有项一致），tooltip 侧直接不追加该行。严禁返回"半成功"。
3. **rc 是 UTF-16LE**：只能脚本改（iconv → 按行处理 → iconv 回写），改完检查 CVT1100 资源重复。
4. **新建 .cpp/.h**：UTF-8 带 BOM；必须同时加进 `PulseBar.vcxproj`（和 .vcxproj.filters）。
5. **语言键分区**：对话框控件文本 `[text]`，菜单文本 `[menu]`；`IDS_xxx` 在 `Language.h` 定义宏 + 18 个 ini 的 `[text]` 加值。中文给精确翻译，其余语言英文兜底。
6. **SampleText 宽度必须 ≥ 实际值文本宽度**，否则窗口宽度不够被裁剪（表现为"不显示"）。
7. **链接前必须杀 PulseBar.exe**（提权 taskkill 弹 UAC）；**手改 INI 顺序 = 杀进程 → 改 ini → 启动**（退出时 SaveConfig 会覆盖）。
8. **菜单单选组 ID 必须连续**；`ON_COMMAND_RANGE` 处理函数参数是 `UINT`。
9. **resource.h 新 ID 不能放进 `#ifdef APSTUDIO_INVOKED` 块**。
10. **两处 tooltip 都要改**：任务栏 `CTaskBarDlg::GetMouseTipsInfo()`（TaskBarDlg.cpp ~674）+ 主窗口 `CPulseBarDlg::GetMouseTipsInfo()`（PulseBarDlg.cpp ~301）。
11. **PowerShell 验证脚本不能写中文注释**（无 BOM UTF-8 被 GBK 误读导致解析错误）；python 用 `%LOCALAPPDATA%\hermes-agent\venv\Scripts\python.exe（按本机实际路径替换）`。
12. **自动隐藏任务栏无法用合成输入唤出**（SetCursorPos/SendInput 都不行）——UI 视觉确认环节需要用户悬停任务栏配合。
13. 新画的自绘窗口必须自己清背景（`WM_ERASEBKGND` 返回 1 + 每帧全幅重绘），参照 SpeedGraphTip 现状。
14. 显示项新枚举的接入触点共 6 个文件：`DisplayItem.h/cpp`、`SkinFile.cpp`、`TaskBarDlg.cpp`、`PulseBarDlg.cpp`（两处 tooltip）、`language/*.ini`。

## 2. 架构设计

### 2.1 数据采集层

```
监控线程(事件驱动,1s) DoMonitorAcquisition()
├─ CPdhGPUUsage        (现有,PDH,GPU利用率——本机坏,留作他机)
├─ CGPUMemoryMonitor   (NVML)
│   ├─ GetDedicatedGpuMemory()        现有
│   ├─ GetNvidiaGpuStatus()           S1新增: util+温度+功耗 一次设备循环
│   └─ GetNvidiaGpuProcesses()        S4新增: 图形进程列表
└─ CDiskSpeedMonitor   (S2新增, winioctl)
    └─ GetDiskSpeed()  \\.\PhysicalDriveN + IOCTL_DISK_PERFORMANCE 差分
```

**CGPUMemoryMonitor::GetNvidiaGpuStatus(int& util, int& temp_c, int& power_w)**
- 一次遍历 NVIDIA 设备：`nvmlDeviceGetUtilizationRates` / `nvmlDeviceGetTemperature(handle,0,…)` / `nvmlDeviceGetPowerUsage`(mW→W 四舍五入)。
- 多卡取 max（功耗、温度、利用率同口径）。NVML 不可用返回 false，三个出参全 -1。
- 现有 `GetNvidiaGpuUtilization()` 重定向到本方法（取 util 字段），调用方改造。
- 温度应用点：`PulseBarDlg.cpp` ~3127 OHM `GpuTemperature()` 之后，`m_gpu_temperature < 0` 才用 NVML 值兜底。
- 功耗应用点：GPU 利用率块附近，受 `IsHardwareEnable(HI_GPU)` 门控；`theApp.m_gpu_power_w`（int，W，-1 不可用）。

**CDiskSpeedMonitor::GetDiskSpeed(read_bps, write_bps)**
- 懒初始化：枚举 `\\.\PhysicalDrive0..15`，`CreateFileW(…, 0, FILE_SHARE_READ|FILE_SHARE_WRITE,…)`（0 访问权不需要管理员），`IOCTL_DISK_PERFORMANCE` 启用并读取 `DISK_PERFORMANCE`（winioctl.h）。
- 每秒差分：`(BytesRead_now - BytesRead_prev) * 1000 / elapsed_ms`。elapsed 由 GetTickCount64 实测。
- 连续 3 次失败 → 置 `m_failed` 不再轮询；任何一次 IOCTL 成功即恢复可用。
- 输出：`theApp.m_disk_speed_available`(bool) + `m_disk_read_speed` / `m_disk_write_speed`(ull B/s)。受 `IsHardwareEnable(HI_HDD)` 门控。
- 口径说明：物理盘总和（含系统盘），与任务管理器"性能-磁盘"同量级。

**GetNvidiaGpuProcesses(std::vector<NvGpuProcess>&)**（S4）
- 符号尝试顺序：`nvmlDeviceGetGraphicsRunningProcesses_v3` → `_v2` → 无后缀；结构 `{uint pid; ull usedGpuMemory;}` 各版本二进制兼容。
- pid→名称用 `Toolhelp32Snapshot(TH32CS_SNAPPROCESS)` 一次快照建表（对提权进程也有效，比 OpenProcess 稳）。
- 按显存降序取 3；无图形进程返回空表（面板隐藏该区）。

### 2.2 超级悬停面板（S3+S4 载体）

改造 `CSpeedGraphTip`（保留类名/文件名/窗口类 `TMLiteSpeedGraphTip`，缩小改动面）。

**数据**：`m_up[60] m_down[60]` 现有；新增 `int m_cpu[60], m_gpu[60]`（0-100）；`AddSample(up, down, cpu, gpu)`（调用点 TaskBarDlg.cpp:1109，每秒无条件采样，与可见性无关——保证弹出即有完整曲线）。S4 的进程列表 `m_gpu_procs` 仅在面板可见或已钉住时每秒刷新。

**布局**（逻辑像素，×DPI）：
```
┌──────────────────────────────────────┐
│ 监控面板                      [○ pin]│ 头行 18px，pin 区 24px 宽点击热区
│ ↑12.3MB/s  ↓4.5MB/s   CPU12% GPU45% │ 值行 16px
│ ▇▇▇▇ 网速曲线(红=下行 绿=上行) ▇▇▇▇ │ 图1 36px，自适应峰值(现有算法)
│ ▁▂▃ CPU(青)/GPU(橙) 0-100% 曲线 ▁▂▃ │ 图2 30px
│ 今日流量 ↑1.2GB ↓3.4GB               │ 16px
│ GPU 65℃ · 45W                        │ 16px（数据无效整行隐藏）
│ ── GPU 进程 ──                       │ S4: 表头 14px（无进程隐藏）
│ chrome.exe          1234MB           │ 行 14px ×≤3
└──────────────────────────────────────┘ 宽 320，高度按启用的区动态累计
```

**主题化**：面板背景/文字取 `FindTaskbarTheme(tb_theme)`（主题面板激活时），无主题用现有深色默认。曲线色固定语义色：下行 `#F06464`、上行 `#50C878`、CPU `#4FC3F7`、GPU `#FFB74D`。

**钉住（12）**：`bool m_pinned`，会话级不落盘。
- 点击头行右侧 pin 热区切换；画一个圆形图钉（实心=已钉，空心=未钉），不用 emoji 字体。
- 钉住时：任务栏 mouse-leave 不隐藏、`HideSpeedGraphTip()`(设置开关关闭/窗口关闭) 强制解除钉住并隐藏。
- 右键面板 = 解除钉住并隐藏；Esc 同。
- 面板已有 `WS_EX_NOACTIVATE`，点击直接收 `WM_LBUTTONUP`，不抢任务栏焦点。

**开关**：沿用 `show_speed_graph_tip`（配置键不变），显示文案升级为"悬停时显示监控面板"（18 个语言文件的 `TXT_SPEED_GRAPH_TIP` 改文案，键名不动）。
