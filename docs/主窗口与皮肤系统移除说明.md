# 主窗口与皮肤系统移除说明

本版本面向只需要任务栏监控显示的使用场景。

## 保留功能

- 任务栏网速、CPU、内存、GPU 显存、磁盘和插件项目显示
- 任务栏主题、悬停监控面板、托盘图标
- 网卡选择、历史流量、任务管理器、插件管理、常规设置
- 开机自启动、硬件监控、配置保存和多语言

## 移除内容

- 主窗口悬浮窗及其绘制、拖动、置顶、透明度、鼠标穿透逻辑
- 主窗口设置页、主窗口颜色设置、皮肤选择和皮肤自动适配对话框
- `CSkinFile` / `CSkinManager` 及皮肤预览、PNG 掩码区域处理
- `IDR_MENU1` 主窗口菜单；托盘右键菜单复用任务栏菜单
- `portable/skins`、`installer/skins` 和源码皮肤目录

`CPulseBarDlg` 仍作为不可见宿主窗口存在。它负责 MFC 消息循环、监控采样线程、托盘图标、历史流量、插件消息和任务栏窗口生命周期；它不会创建可见悬浮窗。

## 使用方式

启动后任务栏窗口由 `config.ini` 的 `show_task_bar_wnd` 控制。托盘左键打开选项设置，托盘右键打开任务栏菜单。

选项设置使用左侧四类导航：

- **显示内容**：监控项目、顺序、显示文字、标签色/数值色、格式和单位
- **外观**：任务栏主题、自定义主题草稿、背景图、字体与颜色
- **位置与交互**：显示器与任务栏位置、悬停方式、双击动作、资源占用图、渲染兼容设置
- **应用与采集**：网卡范围、硬件监控、开机启动、通知区、提醒、语言、更新、采集方式和插件管理

监控项目原先分散在“显示设置”“显示文本设置”“项目颜色”三个入口，现在合并为一张表，插件指标也在其中。自定义主题改为编辑本地草稿，只有外层设置点“确定”或“应用”才提交，取消会丢弃。底部三个按钮对所有页面统一生效。

## 插件系统（保留，仅面向任务栏）

插件机制完整保留，但所有入口都收敛到任务栏面板：

- 任务栏窗口里右键插件显示项 → 「选项」「详细信息」
- 任务栏右键菜单中的插件子菜单会列出该插件的命令（带勾选状态）
- 插件显示项在任务栏中正常绘制文本或自绘（`IsCustomDraw` / `DrawItem` / `DrawItemEx`）
- 任务栏设置页的「显示内容 → 编辑监控项目与顺序…」可勾选、排序、编辑显示文字和颜色，包含插件项目
- 任务栏右键菜单 →「插件管理」可启用/禁用插件

插件 ABI 未改动：`IPluginItem`、`ITMPlugin` 全部接口照旧可用，`GetTaskbarWindowHwnd()` 返回真实任务栏窗口句柄；`GetMainWindowHwnd()` 返回不可见宿主句柄，仅作为兼容值。原有的 `EI_MAIN_WND_*` 扩展信息继续下发兼容默认值，插件无需修改即可在任务栏中继续工作。

## 配置与插件兼容

旧配置中的主窗口和皮肤键会在保存时被主动移除（`[skins]` 段、`skin_*` 段、`plugin_display_str_main_window` 等一并清理），任务栏配置键保持原有格式。`GetMainWindowHwnd()` 和 `EI_MAIN_WND_*` 插件接口仍保留，返回不可见宿主句柄和兼容默认值。

若旧配置里同时关闭了任务栏窗口和托盘图标，启动时会自动补开托盘图标，避免出现无任何可操作入口的情况；新配置默认 `show_task_bar_wnd = true`。

## 设置界面重构与 PulseBar 品牌（2026-10-31 第二轮）

- 设置左侧导航扩为六页：显示内容 / 外观 / 位置与交互 / 网络与采集 / 启动与托盘 / 提醒与语言；删除"更多设置"折叠区
- 修复滚动根因：整页 `ScrollWindow` 在分组框部分可见时按 Windows 文档不会正确重绘（用户截图的重复"背景与形状"），改为逐控件 `SetWindowPos` + 整页重绘（`CTabDlg::MoveChildControls`）
- 修复菜单翻译破坏弹出子菜单的问题：`TXT_` 开头的 popup 此前被 `ModifyMenu(MF_STRING, -1)` 替换成无效命令项，现在保留 `MF_POPUP` 和原 HMENU
- 修复 `ValidWindowOffsetLeft` 把左右偏移校验写到 `window_offset_top` 的错误
- 任务栏窗口 DC 改为在 `OnDestroy`（窗口仍有效时）释放，析构仅兜底
- 外观页在主题模式下隐藏经典配色行（文本/背景颜色、深浅色适配、预设），隐藏后逐控件标脏父窗口避免 DWM 表面残留旧画面
- 右键菜单精简为三组：监控项目、历史流量、网络连接、悬停面板｜设置、插件管理、任务管理器｜关于、显示/隐藏、退出；移除单项"工具""帮助与更新"子菜单
- 品牌更换为 PulseBar：新图标（蓝底白脉搏线）、版本信息、关于对话框（只留版本、开源协议、第三方库）、界面可见文本（18 个语言文件）；注册表自启动键名与配置键保持原名以兼容现有安装
- 重复启动不再弹"已经在运行"对话框：检测到已有实例时新进程静默退出（`no_multistart_warning` 配置键保留但不再使用）
- 设置页控件拉散/重叠的根因修复：分区归属改为读取资源模板生成的静态布局表（不再用运行时坐标推算），滚动改为单次净位移；移动控件后通过“隐藏本页→父窗口擦除→重新显示”彻底清除旧文字和分组框残影
- 上述修复用真实屏幕像素验证：滚动到底再回顶部、切到外观页与网络与采集页，画面均无残留
- 导航和菜单中该进程的通用命令消息（WM_COMMAND）可用于自动化；未使用任何跨进程指针消息

## 已验证（2026-10-31 第二轮）

- Release x64 与 Debug x64 均以退出码 0 编译通过
- 选项窗口六页导航实际渲染正确；显示内容页、外观页（经典与主题两种模式）通过真实屏幕像素采样验证，无控件重叠、无滚动残影；主题切换后经典配色行 `IsWindowVisible` 为 0 且屏幕采样为背景色
- 合并监控项目窗口、设置打开/关闭正常；语言资源检查通过（18 个语言文件无重复键）
- 此前文档中"监控项目表列宽导致 COMCTL32 崩溃"的归因不成立：当时的崩溃由测试脚本向另一进程的列表控件传本地指针引起（WM_USER 范围消息不跨进程封送），程序侧根因未证实；列创建完成后再布局列宽保留为防御性检查
- "自绘显示列"的表述不准确：当前实现是文本"✓"列，共五列（显示/项目/显示文字/标签色/数值色）

## 构建

使用 Visual Studio 2022 Build Tools：

```bat
msbuild PulseBar.sln /t:PulseBar /p:Configuration=Release /p:Platform=x64 /m:1
```

Debug 构建在资源受限的机器上使用 `/m:1`、`MultiProcessorCompilation=false`，并为编译器传入 `/FS`，避免多个编译器同时写入 `vc143.pdb`。
